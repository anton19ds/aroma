# Инструкция: Поля импортированы, но не отображаются на страницах Options

## Проблема
После импорта JSON файлов поля появились в Custom Fields → Field Groups, но не отображаются на страницах "Pure Page Settings" и "FAQ Page Settings".

## Решение

### Шаг 1: Проверьте Location Rules

1. Перейдите в админке: **Custom Fields → Field Groups**
2. Найдите и откройте группу **"Настройки страницы Pure"**
3. Перейдите на вкладку **"Location"** внизу страницы
4. Проверьте, что выбрано:
   - **Param:** Options Page
   - **Operator:** is equal to
   - **Value:** Pure Page Settings
5. Если значения неправильные, исправьте их:
   - Нажмите на выпадающий список "Param" и выберите **"Options Page"**
   - В поле "Value" выберите **"Pure Page Settings"**
6. Нажмите **"Update"** для сохранения
7. Повторите для группы **"Настройки страницы FAQ"** (Value должен быть **"FAQ Page Settings"**)

### Шаг 2: Проверьте Options Pages

1. Убедитесь, что в левом меню админки есть пункты:
   - **Pure Page Settings**
   - **FAQ Page Settings**
2. Если их нет, возможно Options Pages не созданы - проверьте код в `functions.php`

### Шаг 3: Очистите кеш

1. После исправления Location Rules обновите страницу Options Page (F5)
2. Если поля все еще не появляются, попробуйте:
   - Очистить кеш WordPress (если используется плагин кеширования)
   - Выйти и войти в админку заново

### Шаг 4: Альтернативный способ

Если Location Rules не сохраняются через интерфейс:

1. Откройте группу полей в админке
2. Нажмите **"Export"** (чтобы увидеть текущие настройки)
3. Скопируйте JSON код
4. Отредактируйте секцию `"location"` вручную:
```json
"location": [
    [
        {
            "param": "options_page",
            "operator": "==",
            "value": "pure-page-settings"
        }
    ]
]
```
5. Используйте **"Import"** для импорта исправленного JSON

## Проверка

После исправления:
1. Откройте **Pure Page Settings** в меню админки
2. Должны отображаться все поля для редактирования
3. То же самое для **FAQ Page Settings**

Если проблема сохраняется, проверьте:
- Установлен ли плагин ACF версии 6.4.2
- Активирован ли плагин
- Есть ли права на редактирование (capability: 'edit_posts')
