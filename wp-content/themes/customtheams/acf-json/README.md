# Инструкция по импорту ACF полей

## Автоматический способ (рекомендуется)

1. Убедитесь, что плагин **Advanced Custom Fields** установлен и активирован
2. Перейдите в админке WordPress: **Custom Fields → Field Groups**
3. ACF автоматически обнаружит JSON файлы в этой папке
4. Вы увидите группы полей с пометкой **"Sync available"** (если их еще нет в БД)
5. Нажмите кнопку **"Sync available"** для каждой группы:
   - "Настройки страницы Pure"
   - "Настройки страницы FAQ"
6. После синхронизации поля появятся в соответствующих Options Pages:
   - **Pure Page Settings** (в левом меню админки)
   - **FAQ Page Settings** (в левом меню админки)

## Ручной импорт через админку

Если автоматическая синхронизация не работает:

1. Перейдите в **Custom Fields → Tools → Import Field Groups**
2. Скопируйте содержимое файла `group_pure_page.json` и вставьте в поле импорта
3. Нажмите **"Import"**
4. Повторите для файла `group_faq_page.json`

## Проверка

После импорта проверьте:
- В меню админки должны появиться пункты: **"Pure Page Settings"** и **"FAQ Page Settings"**
- При открытии этих страниц должны отображаться все поля для редактирования

## Файлы в этой папке

- `group_pure_page.json` - Поля для страницы Pure
- `group_faq_page.json` - Поля для страницы FAQ

Эти файлы автоматически синхронизируются с БД при сохранении через интерфейс ACF.
